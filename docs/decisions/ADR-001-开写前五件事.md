## 1. 数据智能体对外挂哪几个技能

**结论：先挂 2 个只读技能，不再挂整个 Hermes Chat。**

| skill.id | 名称 | 现网真源 | 对外做什么 | 不做什么 |
|----------|------|----------|------------|----------|
| `collect.strategy.query` | 采集策略查询 | 资产卡 `KB.API.Retrieve.v1` 的 **采集策略子集**（`knowledge/闭环采集策略枚举对应关系.md` + `knowledge/ai_collect/`） | 按 `mission_name` / 产品线 / 关键词返回策略枚举、增项文件、子场景字段 | 不开放整库 `kb.retrieve`（Hive 口径、临时需求、工程文档） |
| `collect.volume.query` | 采集数据量查询 | 资产卡 `ES.API.QueryAiCollect.v1` 的 **count** | 按机型 / 策略 / 协议类 / 日期等白名单槽返回余量数字 | 不返回预览图、不返回可建任务的 DSL、不创建任务 |

**明确不开放（写进 Card 的 `x-sunny.not_exposed`）：**

- 调用模型（Coral / vLLM / 任意推理入口）
- 创建任务（`cvat.create_special_task`）
- 现场拼 SQL / 整段 Hermes Chat
- Ontology 槽取数 `db.query_by_device`、场景库 `db.query_scenes`、生命周期 `db.query_lifecycle`（一期不对外）

内部 Hermes 仍可继续用上述 Skill；**Card 是对外发现面，不是内部工具全集。**

## 2. 工作空间怎么隔离

**结论：Agent 服务账号，不进个人 scratch。** 全文见 [ADR-002](./ADR-002-工作空间隔离.md)。

- 发现和访问必须分开。看见 Card ≠ 能调用。
- 票的 audience 是调用方 `agent_id`，不带登录名。
- 跨 Agent 调用只走服务工作区 / 包装器，不进控制台个人 scratch。
- P0 不分 personal / team / prod；样例 `workspace` 为 `ecovacs.aidata`。

---

## 3. 谁有权让一张 Card 被别人搜到

**结论：在注册中心完成登记的 Agent，默认可被其他同样已登记的 Agent 发现。**

这比立项调研里「登记后只对自己可见、审批后才进搜索」更松：

| 动作 | 谁可以 | 结果 |
|------|--------|------|
| 登记 | 仍受 Registry 写入权限约束（P0 运维代提，不开放自注册） | 成为「已登记 Agent」 |
| 被搜到 | 其他已登记 Agent | 能读公开 Card + 技能列表 |
| 调用 | 另鉴权：短时调用票 + 技能级 `data_class` / `side_effects` | 搜到 ≠ 能调 |

下线 / 禁用仍立刻退出搜索。敏感技能以后走 Extended Card，不靠「不注册」。

---

## 4. P0 调用票

**结论：可以接受 Registry 签发的短时调用票。**

约束（写进规格，避免票变成第二套长期密钥）：

- 短 TTL，audience 绑定调用方 `agent_id` + 被调 `skill.id`
- 票只证明「这次允许调这个 skill」，不替代包装器 / Guard / 领域 L4
- **禁止把票、token、密码、连接串写进 Card**
- P0 不先上 OAuth；P1 再评估公司 SSO

---

## 5. ChatBI 是否同意至少一个 L1 模板契约

**结论：可以统一 L1 模板技能，并额外挂两档能力。**

ChatBI 对外技能意向（契约草稿见 [ChatBI 技能契约](../specs/chatbi-skill-contract.md)）：

1. **L1 模板** — 统一槽位契约（Hub 互调的主路径）
2. **知识问答** — 仓名词 / 表口径，对标本仓 `kb.retrieve` 的只读知识档
3. **生成 SQL 取数** — 必须拆成「出 SQL 计划」和「执行取数」；执行默认关，Chat 出口仍禁止泄 SQL

原门闩仍然有效：不整段转发 `/v1/chat`，闭环融合主路径不改口走 ChatBI。  
**八字段表已搁置**（2026-09-18）：现在不必填，也不挡数据智能体样例冻结。ChatBI Card 在真正要做 M3 之前不登记。
