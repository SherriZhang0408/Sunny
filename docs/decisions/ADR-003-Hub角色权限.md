# ADR-003 Hub 角色权限

| 项 | 内容 |
|----|------|
| 状态 | **已采纳** |
| 日期 | 2026-09-18 |
| 上游 | [ADR-002](./ADR-002-工作空间隔离.md) 未纳入项：谁能提交 / 更新 Card |

> 拍板：管理台分管理员与开发者。管理员拥有全部权限；开发者可查看名片、发布自己的智能体，并只能改自己创建的智能体。

---

## 结论

1. **Hub 登录身份 ≠ 调用身份。** 管理员 / 开发者只约束控制面（看卡、发布、改卡、删卡、账号）。短时票仍按 ADR-002，audience 只有 `agent_id`，不写登录名。
2. **两个 Hub 角色。** `admin` 全权限；`developer` 只读名片目录，可 `hub` 发布，且仅对自己 `created_by` 的智能体做增技能 / 改说明 / 删卡。
3. **机器通道保留。** `SUNNY_ADMIN_TOKEN`、enroll token、Agent key 仍可用。Agent key 只能更新自己的 Card，不能删别人的、也不能走 Hub 账号管理。
4. **所有权落库。** `agents.created_by` 记发布者 `user_id`。历史 Hub 填入的卡回填给 `usr_admin`；Agent 自注册仍可为空，只许管理员改。

---

## 默认本地账号

| 用户名 | 密码（可用环境变量覆盖） | 角色 |
|--------|--------------------------|------|
| `admin` | `SUNNY_ADMIN_TOKEN`（默认 `sunny-dev-admin`） | 管理员 |
| `developer` | `SUNNY_DEVELOPER_PASSWORD`（默认 `sunny-dev-developer`） | 开发者 |
