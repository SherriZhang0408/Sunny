# Hub 手工 QA 清单


| 项   | 内容                                                                               |
| --- | -------------------------------------------------------------------------------- |
| 对象  | SUNNY · Agent Hub（`web/`，Registry 同进程静态页）                                                |
| 不是  | pytest 契约 / 抽 `app.js` 函数 / TestClient 接口（见第 12 节）。那些不点页面，代替不了动画、对话框、下载、主题观感和窄窗 |
| 角色  | [ADR-003](../decisions/ADR-003-Hub角色权限.md)：`admin` 全权限；`developer` 看卡 + 维护自己发布的卡 |
| 过线  | 每一节主路径 + 标明的失败路径都点过；登录态换页不丢；页面上**没有** `sak_` / 完整调用票 / 密码                        |


勾选用例时写日期、浏览器、账号角色。不要把票、key、密码贴进本文件或截图仓库。

pytest 已覆盖登录深链算法、发布三分类、设置 prefs、审批筛选项、会话令牌不能当调用票。**本清单只手点自动化看不到的部分**：原生 `<dialog>`、汇聚动画、文件下载、主题/字体是否真的上屏、刷新后 hash 还在、窄窗会不会挤爆。

## 0. 开测前

- [x] Registry 用脱离会话的方式拉起（前台终端被 abort 后 `:8088` 会断）：

```bash
cd ~/PycharmProjects/Sunny
setsid -f python3 -m sunny_registry
curl -sS http://127.0.0.1:8088/api/v1/health
```

- [x] 浏览器打开 `http://127.0.0.1:8088`（局域网用握手包里的 IPv4，不要用名片里的 `0.0.0.0`）
- [x] 桌面宽度（约 1280）走完全部节；改过布局再看一版窄窗（约 390）
- [x] 中文不是方框（缺字体时会花屏；页面已挂 Noto Sans SC）
- [x] 本机默认账号（可用环境变量覆盖，见 ADR-003）：`admin` / `sunny-dev-admin`，`developer` / `sunny-dev-developer`
- [x] 库里至少有 `aidata.hermes`（管理台填入）和一张别人的卡（如 `lab.inspector` / 开发者自己发的）才能做权限对照
- [ ] 先跑自动化（不替代下面手点；当前全库应全绿）：

```bash
python3 -m pytest -q
```

- [ ] 硬刷新一次，确认加载的是当前 `app.js?v=48`（避免旧脚本还在切发布页、还缺「已通过」）
