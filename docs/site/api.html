鉴权

身份怎么带能做什么
管理员登录后 Bearer 会话，或 Authorization: Bearer $SUNNY_ADMIN_TOKEN全部读写、账号、活动、关系图、含令牌握手包
开发者登录后 Bearer 会话看已登记卡；发布自己的卡；只改/删 created_by 是自己的卡。不能出票
AgentX-Sunny-Agent-Key: sak_… 或 Bearer 同一把 key搜对等、读卡、心跳、更新自己、要票
首次自注册X-Sunny-Enroll: $SUNNY_ENROLL_TOKEN只允许 enrollment_source=self 的创建

Hub 角色不进调用票。会话令牌 typ=session 拿去 POST /tickets/verify 会 401 not a call ticket。缺 caller / callee / skill 的残票是 401 malformed ticket。票与 key 不写进 Card。示例里的 sak_… 是占位，不要贴真实 key。

发现

搜到卡 ≠ 能调。公开卡剥 restricted；搜索默认只要 online。

方法路径鉴权说明
GET/api/v1/health匿名ok、service、public_url、join、agents、fts、sweep
GET/api/v1/join · /join.md匿名；?include_token=1 需管理员。?download=1 触发下载握手包。匿名无 enroll token
GET/api/v1/agents对等或 Hub可滤 q、workspace、discovery、approval_status、enrollment_source、runtime_status。管理员可 include_disabled
GET/api/v1/agents/{id}同上详情 + Card。can_manage / card_view。对等拿公开卡
GET/api/v1/agents/{id}/extended对等或 Hub完整卡。ETag = Card version；Vary: Authorization
GET/api/v1/agents/{id}/a2a同上剥 x-sunny 与 restricted。支持 If-None-Match → 304
GET/api/v1/search对等或 Hubskill tag workspace q。只出对等可见、只读、public/internal。默认 online。管理员 alive=0 可看下线。q 走 FTS5
GET/api/v1/card-changes对等或 Hubsince agent_id limit。拉取升版，不推送
 
curl -sS http://127.0.0.1:8088/api/v1/health
curl -sS -H "X-Sunny-Agent-Key: sak_…" \
  "http://127.0.0.1:8088/api/v1/search?skill=collect.strategy.query"

常见错误：未登录/无 key → 401；对等看不见 private / 待审批 → 404；搜索无命中 → items: []。

接入登记

方法路径鉴权说明
POST/api/v1/agentsHub 用户，或 Enroll + selfbody {card, enrollment_source: self|hub}。Hub 发布记 created_by
POST/api/v1/agents/pullHub 或 Enrollbody {url, enrollment_source?, agent_id?, discovery?}。缺的 agent_id 仅管理员可 overlay；discovery 拉取方可覆盖。已存在则刷新，不重发 key。仍走 schema / 禁密钥
POST/api/v1/agents/{id}/refresh管理员 / 创建者 / 本 Agent按库里 card_source_url 重抓；失败留旧卡
POST/api/v1/agents/{id}/heartbeat管理员或本 Agent key心跳
 
curl -sS -X POST http://127.0.0.1:8088/api/v1/agents \
  -H "X-Sunny-Enroll: $SUNNY_ENROLL_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"enrollment_source":"self","card":{...}}'

curl -sS -X POST http://127.0.0.1:8088/api/v1/agents/pull \
  -H "Authorization: Bearer <hub-session>" \
  -H "Content-Type: application/json" \
  -d '{"url":"http://10.0.0.8:8091","discovery":"approval_required"}'

常见错误：坏 JSON / schema → 400；非 http(s) 或元数据主机 → 拉取失败不入库；file:// 与链路本地地址被拒；enroll 不能覆盖已有卡。

出票与调用链

Registry 签发短时票并验票，不转发业务。sidecar 验票后本地执行。

方法路径鉴权说明
POST/api/v1/tickets管理员或 Agent key（开发者不可）body {caller_id?, callee_id, skill_id}。Agent 的 caller 强制为自己。票带 card_version
POST/api/v1/tickets/verify同上body {ticket, callee_id?, skill_id?}。升版后旧票作废。拒会话令牌与残票
POST/api/v1/invocations同上上报一次调用，画关系图。body {caller_id?, callee_id, skill_id, status, trace_id?, ticket?}
POSTsidecar /sunny/invoke/{skill_id}Authorization: Bearer <ticket>body {slots, trace_id?}。sidecar 回 Registry 验票后再执行
 
curl -sS -X POST http://127.0.0.1:8088/api/v1/tickets \
  -H "X-Sunny-Agent-Key: sak_…" \
  -H "Content-Type: application/json" \
  -d '{"callee_id":"aidata.hermes","skill_id":"collect.strategy.query"}'

curl -sS -X POST http://127.0.0.1:8091/sunny/invoke/collect.strategy.query \
  -H "Authorization: Bearer <ticket>" \
  -H "Content-Type: application/json" \
  -d '{"slots":{"mission_name":"living_room"},"trace_id":"demo-1"}'

常见错误：private / 待审批 / restricted / write → 对等 403；deprecated 或 disabled 拒新票 → 409；技能不在卡上 → 404；槽校验失败 → sidecar 400。票明文只在签发响应里出现一次，活动页最多留 jti。

Hub 管理

方法路径鉴权说明
POST/api/v1/auth/login匿名{username, password} → 会话 token + user
GET/api/v1/auth/meHub 会话当前用户与权限
GET · POST/api/v1/users管理员账号列表 / 添加
DELETE/api/v1/users/{user_id}管理员不能删最后一名管理员
PUT / PATCH / DELETE/api/v1/agents/{id}管理员、创建者或本 Agent（删仅管理员或创建者）整卡 / 局部技能 / 删除
POST…/disable · …/deprecate · …/enable管理员停用对等 404；弃用能读不能出新票；恢复 registered
POST…/keys管理员新 sak_ 明文只回一次
POST…/probe管理员或本 Agent探 Card URL，不代发业务
GET…/revisions对等或 Hub变更历史列表
GET…/revisions/{rev}仅管理员某一版 Card 快照
GET/api/v1/approvals管理员status=pending|rejected|approved，默认 pending
POST…/approve · …/reject管理员拒绝 body {reason}。开发者不能自审通过
GET/api/v1/graph管理员节点 + 调用边
GET/api/v1/activity管理员kind trace_id q limit（默认 80，上限 200）
 
curl -sS -X POST http://127.0.0.1:8088/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"sunny-dev-admin"}'

Hub 静态：GET /、/assets/*；其余非 api/ 路径回 SPA。错密码 401「用户名或密码错误」。

MCP

自研 JSON-RPC（Python 3.8，不上官方 SDK）。只发现，不签发票、不代调。

方法路径说明
GET/mcp匿名。工具清单 + instructions
POST/mcpJSON-RPC：initialize / tools/list / tools/call / ping
工具对应 REST不返回
list_agentsGET /agents（online、对等可见）票、key、restricted
search_registryGET /search接口 URL、票、key
get_card公开卡restricted、已发票
get_extended_cardGET /extended票、key
describe_access无单独 REST已签发的票（只给 sidecar / 出票路径配方）
list_card_changesGET /card-changes票
joinGET /join 摘要enroll token。匿名可调

除 join 外需要 sak_ 或 Hub 会话。stdio：python3 -m sunny_registry.mcp_stdio，见 工程说明。
