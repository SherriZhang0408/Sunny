企业内控制面

SUNNY · Agent Hub

策展型 Agent 注册中心。不替代各智能体的决策，只让它们按名片互相发现、按策略互相调用。

名字来自电影 I, Robot 里的机器人桑尼。本机 / 局域网已验证，不是公网市场。

问题

要解决什么

  • 每次对接都是点对点：基址、鉴权、槽位写死在调用方。
  • 对方一换接口，调用方全改；新 Agent 没有标准「怎么介绍自己」。
  • 能力在对方脑子里，不在目录里。
  • 同事不会为了接入把业务重写成完整 A2A Server。
一句话

只做控制面，不做运行时

企业内策展注册中心 + 薄适配器。发现谁在、会什么、谁看得见、版本与心跳。

不造对话引擎，不当调用网关，不逼业务 Agent 改内核。

原则

发现 ≠ 访问

搜到名片 目录、公开卡、MCP 工具。知道对方有什么技能、接口在哪。
才能调用 短时调用票 + 直打 sidecar。private / 待审批 / 弃用 / restricted 出不了新票。

登录身份不进调用票。看见 ≠ 能调。

现网已落地

一期已经有什么

  • 登记：管理台填入、网址同步、Agent 自注册。
  • 审批：approval_required 须管理员通过；开发者不能自审。
  • 出票与探活：HMAC 短 TTL；周期探活 / 重抓；升版旧票作废。
  • 两户：aidata.hermes 真技能；lab.echo 跨进程回声。
管理台

六页，顶栏四字

浏览目录 名片、来源、审批筛
调用关系 节点与边（管理员）
活动动态 搜索 / 出票 / 调用对账
发布登记 主动登记 / 网址同步 / 发给智能体
账号管理 仅管理员
系统设置 五主题，只存在本机
两户

一条真技能，一条回声

  • aidata.hermes：sidecar :8091。collect.strategy.query 进程内枚举；volume 无包装器也算调通。
  • lab.echo：HTTP :8092 + sidecar :8093。echo.ping 可搜可调；echo.secret 只在 Extended Card。
  • 不改 Hermes 内核。ChatBI 八字段搁置；第二户不是 ChatBI。
边界

刻意不做什么

  • 不当调用网关：Registry 不转发业务。
  • 不改 Hermes 内核 / SOUL；图像闭环禁止改道。
  • 不做公司 SSO、不做外置 agentgateway（以后）。
  • 不催 ChatBI 八字段；不收官方 MCP 商店或 Prompt 仓。
演示路径

本机十分钟能走通

  • 起 Registry → 浏览器 http://127.0.0.1:8088 → admin 登录浏览目录。
  • 起 Hermes sidecar → Hub 上 aidata.hermes 变 online。
  • python3 -m sunny_client --skill collect.strategy.query --slots '{"mission_name":"living_room"}'
  • 可选再起 echo 两进程，调 echo.ping。

这是本机 / 局域网路径，不是「已上生产」声明。
