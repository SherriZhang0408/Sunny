SUNNY 管什么

  • 智能体名片、技能与版本
  • 可见范围、审批状态与生命周期
  • 短时调用票、心跳、探活与活动记录
  • REST、MCP 和握手包形式的发现入口

SUNNY 不接管什么

  • 不集中复制各系统业务数据
  • 不替代原系统的数据与审批权限
  • 不充当业务流量网关或对话编排器
  • 不要求智能体重写内核
