# 注册机制对具身协作的启发

> **归档说明（2026-09-22）：** 对话备忘。现行合同仍是 [ADR-001](../decisions/ADR-001-开写前五件事.md)、[ADR-002](../decisions/ADR-002-工作空间隔离.md)、[策略门闩](../specs/policy.md)。本文不把「群」写成已上线功能。

| 项 | 内容 |
|----|------|
| 日期 | 2026-09-22 |
| 性质 | 架构备忘（寻呼台、联邦学习 GB/T 46284—2025、车联网、蜂群类比压成建设原则） |
| 对照系统 | SUNNY · Agent Hub：策展 Registry + sidecar。发现 ≠ 访问。Registry 不代理业务 |
| 已落地的相关行为 | 名片 / 技能 / 标签搜索、短时调用票、审批、停用与弃用、升版作废、撤权即停 |

> 一句话：  
> **注册中心发号码、划定谁能拨、收回已发出的票。跨户同类型产品共用策略模板；同一家庭里不同设备互相介绍后直接协作。户内轨迹留在本户。**

## 1. 当前注册机制已经提供什么

SUNNY 是控制面，不是业务交换机。

```text
设备 / 智能体
  登记名片（谁、会什么、在哪、标签）
  心跳（还在不在）
        │
        ▼
   Registry：搜索、审批、出票、作废
        │  票绑定 caller / callee / skill / card_version，短 TTL
        ▼
   调用方直打对方 sidecar
   sidecar 验票后在本地执行
   停用、拒绝、升版 → 未过期票作废；进行中的调用再验失败则丢掉结果
```

和具身产品直接相关的现有零件：

| 零件 | 协作里起的作用 |
|------|----------------|
| 名片 + 技能 | 公告。对外只暴露约定技能，不暴露设备内部工具全集 |
| 标签、`skill=` 精确搜索、全文检索 | 按「会同一件事」找同群，而不是拉全库名单 |
| `workspace` | 已有工作空间字段，可用来表达产品线或组织，还不是家庭标识 |
| 短时调用票 | 看见名片 ≠ 能调用。票不带登录名，不进个人工作区 |
| 审批 / 停用 / 弃用 / 升版 | 加入和退出是人审加生命周期，不是默认全网可达 |
| 撤权即停 | 退出或策略升版后，旧票不可用；sidecar 上尚未结束的调用不再返回业务结果 |
| Registry 不转发 | 清扫过程、户内传感器不经过注册中心 |

ADR-001 的 `collect.strategy.query` 是策略口子的现成形状：返回策略枚举，不返回画面、名单或可执行的原始查询。

## 2. 跨家庭：同类型具身产品

这是横向协作。特征相同、样本不同：同一型号、同一技能、同一场景标签，每户的地面和作息不同。

注册机制提供的帮助：

1. **每户设备自己登记。** 发现接口不属于产品大脑。扫地机仍在用户家里决策，sidecar 只负责被找到和验票。
2. **按技能和标签组群。** 「客厅清扫」「地毯」「夜间」这类标签用来圈同一类服务，而不是把所有入户设备互相打开。
3. **策略服务当领航车。** 群里对外的是一个策略技能：领取模板，交回「这个模板是否有效」的汇总。各户向这个服务出票调用，不向另一户的机器人要传感器。
4. **执行留在本户。** 票的受众是智能体，不是这一户的人。家庭地图、影像、作息不进入名片，也不进入注册中心。
5. **退出立即生效。** 这一户关闭共享、策略升版或服务被停用时，已发出的票作废，正在拉取策略的调用停止。

类比收敛在同一条边界上：

| 来源 | 跨户时对应什么 |
|------|----------------|
| 寻呼台 | 中心只发号码，两台机器自己联系 |
| 联邦学习横向 | 交换策略参数或模板效果，原始样本不出户 |
| 车联网编队 | 同类车共用间距策略，各自用自己的传感器执行 |
| 工蜂信息素 | 巢门口一条会过期的公共痕迹，不是另一只蜜蜂的飞行记录 |

跨户不做的事：两户机器人点对点交换原始观测。一条过细的策略会反推出户型。信息素放在策略服务上。

## 3. 同一家庭：不同智能设备

这是纵向协作。样本相同、特征不同：扫地机、冰箱、门锁看的是同一套房间，各自掌握不同能力。

注册机制提供的帮助：

1. **一次介绍，之后直连。** 家庭里的设备都登记到同一注册中心。设备 A 按技能找到设备 B，拿到短时票，直接调用 B 的 sidecar。注册中心不转发电话内容。
2. **能力留在原设备。** 门锁不把开锁凭证交给扫地机；扫地机调用的是门锁已经公布的那一项技能。这和「要大数据就对接 ChatBI，不要自己接数仓」是同一条规则。
3. **互访范围是这一户已经登记的设备。** 默认可见的是已登记且被允许发现的名片。私有、待审批、已停用的设备不会变成家庭里谁都能调的对象。
4. **户内轨迹不出户。** 设备之间可以交换这一次任务需要的结论（「客厅现在可清扫」），不把另一台设备的原始日志抄进注册中心。
5. **其中一台被停用或升版，家庭里正在进行的调用停下来。** 撤权即停对户内和跨户是同一套门闩。

车联网里这是车与车：路侧单元介绍附近的车，变道本身在两车之间完成。联邦学习里这是纵向：先对齐「是不是同一户」，再交换这一户各设备算出来的中间结果。

## 4. 两圈协作怎么叠在同一套注册上

```text
跨户（横向，同技能 / 同标签）
  各户设备 ──领取/交回策略模板──▶ 策略服务
  注册中心只回答：这一群有哪些策略服务、谁已加入、票是否还有效

户内（纵向，同一家庭、不同设备）
  扫地机 ──介绍一次──▶ 注册中心 ──找到──▶ 门锁 / 冰箱
                └── 之后直打对方 sidecar，过程不进注册中心
```

| | 跨户同类型 | 户内不同设备 |
|--|------------|--------------|
| 关系 | 横向：技能相同，家庭不同 | 纵向：家庭相同，能力不同 |
| 注册中心 | 按技能和标签列出策略服务，并要求明确加入 | 让本户设备互相发现 |
| 调用对象 | 策略服务 | 另一台已登记设备的某项技能 |
| 交换物 | 策略模板、模板是否有效的汇总 | 这一次任务的结论 |
| 留在本地 | 户内地图、影像、作息、原始传感器 | 各设备自己的凭证和原始日志 |
| 退出 | 退出群、停用、升版 → 旧票作废，进行中的调用停止 | 同一套撤权 |

## 5. 可以抽出来建设 SUNNY 的原则

下面是思想，不是新功能清单。标成「已有」的，继续守住；标成「以后」的，单独立项再做。

### 已有，继续当作建设原则

1. **公告、授权、执行分开。** 名片是公告，调用票是授权，sidecar 是执行。看见目录不等于能调用。
2. **中心是路侧单元。** 它发号码、记录谁调过谁、收回票。它不保存业务结果，不代理清扫或开锁。
3. **对接能力方，不对接背后的库。** 别人要策略，就调公布了策略技能的那一个智能体。
4. **不造一个包办所有家庭的大智能体。** 对外技能是发现面，不是设备内部工具的全集。
5. **调度方可以知道任务发生过，不能看见载荷。** 活动记录 caller、callee、skill、票的编号，不记录户内数据。
6. **授权取消后，正在进行的调用停下来。** 停用、审批拒绝、升版作废未过期票；sidecar 再验失败则丢掉结果。弃用仍允许旧票用到过期，这是另一条生命周期，不要和撤权混用。
7. **身份是智能体，不是人。** 调用票不带登录名，不进个人工作区。跨户的群也按技能和标签建，不按用户画像建。

### 以后可以长成的抽象

这些能从现有零件长出来。现在没有单独的「群」表或家庭标识。

| 抽象 | 含义 | 现有零件 | 还缺什么 |
|------|------|----------|----------|
| 群 | 同一技能、同一标签、明确加入的一组设备 | 技能搜索、标签、审批 | 加入和退出作为一等对象；退出走现成撤权 |
| 策略服务 | 领航车 / 信息素。只发布模板和汇总 | `collect.strategy.query` 这种只读、有边界的技能 | 名片上写明「返回模板，不返回轨迹」 |
| 家庭范围 | 户内纵向协作的发现边界 | `x-sunny.scope=household` 加同一 `workspace` | 还没有单独的家庭账号。不要用用户账号代替 |
| 路段 | 只看见同向、同类、附近 | 搜索过滤、私有 / 待审批 / 停用 | 默认不要把全部已登记设备当成一个大群 |
| 信息素过期 | 公共策略会失效 | 票的 TTL、升版作废、撤权即停 | 策略模板自己的版本，沿用 Card `version` 即可 |

### 明确不搬进 SUNNY 的

- 联邦学习的求交、同态、差分隐私和建模。那是数据方家里的计算，不是注册中心的模块。
- 车联网式的高频状态广播，以及指挥所有设备的交通大脑。
- 跨户机器人两两交换原始观测。
- 用注册中心聚合各户业务结果。结果只回到被授权的那一方，由对方的 sidecar 交回。

## 6. 和这次对话的对应关系

| 讨论 | 收成的判断 |
|------|------------|
| 寻呼台 / 具身设备注册后直连 | 注册中心不是交换机。户内、跨户都是介绍之后直连 |
| 对接 ChatBI，不接数仓 | 户内其他设备调用已公布的技能；跨户调用策略服务 |
| 联邦学习八类参与方和三模块 | 注册中心只做基础里的发现、授权、作废，加上管理里的名片和审批。计算留在设备侧 |
| 取消授权后任务立即停止 | 已落地为撤权即停 |
| 车联网路侧单元 / 编队 | 注册中心是路侧单元；跨户同类型是编队，不是全网互访 |
| 工蜂 / 工蚁 | 协作读同一条会过期的策略痕迹。个别路线留在本户 |
